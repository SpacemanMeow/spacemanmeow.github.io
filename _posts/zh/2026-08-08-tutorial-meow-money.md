## 应用简介

Meow Money Manager（喵窝记账）是一款设计用于个人财务管理的可爱卡通风格[记账应用](/zh/glossary/what-is-an-expense-tracker/)。它以猫主题界面，将可爱设计与强大功能结合，帮你轻松管理个人财务。应用支持中文、英文、印尼语、泰语、葡萄牙语等多语言界面，安卓 [Google Play 下载](https://play.google.com/store/apps/details?id=com.glgjing.money.manager.bookkeeping.meow&hl=en) 与 iOS [App Store 下载](https://apps.apple.com/us/app/meow-money-manager/id1528852284) 均可使用。

记账应用能否长期用下去，往往取决于两件事：记一笔够不够快，以及数据会不会让你放心。Meow Money Manager 用猫主题和 400+ 图标把"打开它"变得没那么枯燥，同时把数据默认留在本机、不要求注册账号，免去你为一款记账软件再开一个云账号的顾虑。下面这份指南按真实使用顺序展开——先记下每一笔，再设预算、看统计，最后打理资产、账本与报销。功能很多，但不必一次全用上，从最基础的记账开始即可。

## 首次使用

主界面包含以下主要部分：
- 记账按钮：位于右下角，用于快速添加记账记录
- 底部导航栏：包含记账、统计、资产、设置四个选项
- 顶部横幅：显示当前账本与资产概览

第一次打开建议先花一分钟认一下这三块：右下角的记账按钮是一切的起点，底部四个标签分别通往记录、分析、资产与设置，顶部横幅则让你随时知道当前在哪个账本、总资产大概多少。熟悉之后，日常绝大多数操作都能在两三次点击内完成。

## 记账功能

Meow Money Manager 的记账功能非常直观，支持三类记录：支出、收入与转账。支出和收入记录"钱从哪来、到哪去"，转账则记录钱在你自己几个账户之间的流动——后者不算消费，所以单独处理，避免把存款搬家误记成一笔开销。

### 添加支出或收入记录

1. 点击首页底部记账按钮
2. 在弹出的记账界面，切换到"支出或收入"标签
3. 选择适当的分类图标（如餐饮、购物、交通等）
4. 输入金额
5. 选择支付方式（资产）
6. 选择账本
7. 添加备注（可选）
8. 点击确认完成记账

![Record 主界面：新增](/assets/images/blog/record_add.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：账本](/assets/images/blog/record_add_ledger.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：账户资产](/assets/images/blog/record_add_assets.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：备注](/assets/images/blog/record_add_remark.webp){: width="180" .normal }

养成随手记的习惯比追求分类完美更重要：哪怕只填金额、选个大类的图标，也比事后再回想强。备注是个好用的补充——"和朋友吃火锅""打车加班"这类一句话，日后看统计时能立刻想起钱的去向。支付方式（资产）这一项别忽略，它决定了这笔钱从现金、银行卡还是信用卡里扣，直接影响资产余额的准确性。

### 转账功能

1. 点击首页底部记账按钮
2. 在弹出的记账界面，切换到转账标签
3. 选择源资产与目标资产
4. 输入转账金额
5. 输入手续费（可选）
6. 选择账本
7. 添加备注（可选）
8. 点击确认完成转账

![Meow Money Manager 主界面与账户总览：转账](/assets/images/blog/record_add_transfer.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：记一笔](/assets/images/blog/record_add_charge.webp){: width="180" .normal }

转账的典型场景是把工资从银行卡转进余额宝、从现金存进银行。因为源和目标都是你自己的资产，记成转账才不会让总支出虚高。有手续费时填进"手续费"，账目会更贴近现实。

## 预算管理

Meow Money Manager 支持多种预算管理，含每天、每周、每月、每年与自定义周期预算。预算的作用是给消费设一道提醒线：快超支时你能提前收手，而不是月底看账单才后悔。它可以同时跑多个预算，比如一个"每月总支出"加几个"餐饮""购物"分类预算。

### 添加预算

1. 在主界面点击预算横幅，或从设置进入预算管理
2. 点击"添加预算"按钮
3. 选择预算类型（每天、每周、每月、每年或自定义）
4. 点击"添加分类预算"，选择要设预算的分类
5. 输入总预算金额，或为每个分类输入预算金额
6. 输入预算名称
7. 点击确认完成预算创建

![Budget 主界面](/assets/images/blog/budget_manage.webp){: width="180" .normal } ![Budget 主界面：新增](/assets/images/blog/budget_add.webp){: width="180" .normal } ![Budget Add 主界面](/assets/images/blog/budget_add_period.webp){: width="180" .normal } ![Budget Add 主界面：分类](/assets/images/blog/budget_add_category.webp){: width="180" .normal } ![Budget Add 主界面：金额](/assets/images/blog/budget_add_amount.webp){: width="180" .normal }

设预算时别一上来就照理想值填：先按过去一两个月的实际花费打个折，等执行一段时间后知道自己的真实节奏，再逐步收紧。总预算适合掌控大盘，分类预算适合盯住容易失控的方面（比如外卖或购物）；两者搭配，既能看整体又抓得住细节。

### 预算追踪

在预算详情页，你可以查看：
- 总预算与已用金额
- 剩余预算与剩余天数
- 日均预算
- 各分类预算使用情况

![Budget Add 主界面：详情](/assets/images/blog/budget_add_detail.webp){: width="180" .normal }

"日均预算"这项特别实用：把剩余金额摊到剩下的天数，你就知道接下来每天大概能花多少。如果发现日均突然变得很低，说明前半段花得太快，后面几天该克制一点了。

## 统计与分析

Meow Money Manager 提供多种统计分析功能，帮你了解财务状况。记账的目的不是把数字堆起来，而是回答"我的钱到底花在哪"——统计页就是用来找答案的地方。它支持按天、周、月、年与自定义时间范围查看，短到几天、长到一年都能覆盖。

### 统计类型

1. 在主界面点击底部统计导航栏进入统计页
2. 选择统计时间范围：天、周、月、年或自定义
3. 查看不同类型的统计图表

- **饼图统计**：饼图展示各分类支出与收入占比，帮你了解钱花在哪。
- **柱状图统计**：柱状图展示每日或每月收支，帮你了解收支趋势。
- **日历视图**：日历视图展示每日收支，颜色深浅表示金额大小。

![App 主界面：统计](/assets/images/blog/stats.webp){: width="180" .normal } ![App 主界面：日期](/assets/images/blog/stats_date.webp){: width="180" .normal } ![App 主界面：图表](/assets/images/blog/stats_chart.webp){: width="180" .normal } ![App 主界面：饼图](/assets/images/blog/stats_pie.webp){: width="180" .normal } ![App 主界面：直方图](/assets/images/blog/stats_hist.webp){: width="180" .normal }

三张图各有分工：饼图看结构（哪类占比最大），柱状图看趋势（哪天花得特别多），日历视图看分布（是不是每周末都有一笔大额）。把它们连起来读，比单看任何一张都有效——比如饼图显示餐饮占比高，再切到日历看看是不是集中在外食的周末。

## 资产管理

Meow Money Manager 支持管理多种资产，如现金、银行卡、信用卡等。把资产登记进应用，记账时选对支付方式，余额才会跟着每一笔收支自动变化；时间一长，你就有了一份随时间更新的资产快照。

### 添加资产

1. 在主界面点击底部资产导航栏进入资产页
2. 点击"添加资产"按钮
3. 选择资产类型
4. 输入资产名称
5. 输入初始金额
6. 选择资产图标
7. 点击确认完成资产添加

![Meow Money Manager 主界面与账户总览：账户资产（2）](/assets/images/blog/assets.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：新增](/assets/images/blog/assets_add.webp){: width="180" .normal }

初始金额建议填开始使用那一刻的真实余额，这样后续的收支变化才有意义。资产类型可以覆盖现金、银行卡、信用卡，也包括股票、基金等；名字起得具体一点（如"工资卡""日常零钱"），记账时就不容易选错。

### 资产详情

点击一个资产进入详情页，可查看：
- 资产余额
- 资产收支记录
- 资产趋势图表

![Meow Money Manager 主界面与账户总览：详情](/assets/images/blog/assets_detail.webp){: width="180" .normal } ![Assets Detail 主界面](/assets/images/blog/assets_detail_transfer.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：趋势曲线](/assets/images/blog/assets_curve.webp){: width="180" .normal } ![Assets Curve 主界面](/assets/images/blog/assets_curve_tip.webp){: width="180" .normal }

趋势曲线能看出某个账户是稳步增长、还是被某几笔大额拉低。信用卡用户尤其要留意余额变化——把还款记成转账，就能清楚区分"花掉的钱"和"还掉的欠款"，避免重复计入支出。

## 账本管理

Meow Money Manager 支持创建多个账本，管理不同类型的收支。账本像是记账本里的"分册"：个人日常、家庭开支、旅行花销可以各归各的，统计也各自独立。对想把生活分块管理的人来说，这比在一个大清单里翻找清楚得多。

### 添加账本

1. 在主界面点击账本横幅，或从设置进入账本管理
2. 点击"添加账本"按钮
3. 输入账本名称
4. 选择账本图标
5. 点击确认完成账本创建

![Ledger 主界面](/assets/images/blog/ledger_filter.webp){: width="180" .normal } ![Ledger 主界面：管理](/assets/images/blog/ledger_manage.webp){: width="180" .normal } ![Ledger 主界面：新增](/assets/images/blog/ledger_add.webp){: width="180" .normal }

账本不必建太多——从"日常""旅行"这类真正会分开统计的场景开始就好。名字和图标选得直观些，切换时一眼就能认出来。

### 切换账本

1. 记账时，点击账本选择器
2. 从弹出的账本列表中选择要用的账本
3. 选择完成后，显示该账本的记账记录

![Meow Money Manager 主界面与账户总览：账本（2）](/assets/images/blog/record_add_ledger.webp){: width="180" .normal }

一个容易忽略的习惯：记每一笔之前先确认当前账本对不对。把旅行开销记进日常账本，回去后再挪动就麻烦了；花一秒看一眼选择器，能省下事后整理的功夫。

### 账本统计

点击一个账本进入详情页，可查看该账本：
- 收支统计
- 预算使用情况
- 详细记账记录

![Ledger Detail 主界面](/assets/images/blog/ledger_detail_record.webp){: width="180" .normal } ![Ledger Detail 主界面：统计](/assets/images/blog/ledger_detail_stats.webp){: width="180" .normal } ![Ledger Detail 主界面：日期](/assets/images/blog/ledger_detail_date.webp){: width="180" .normal }

分账本统计的价值在于回答具体问题：这趟旅行到底花了多少？这个月的家庭开销和上月比如何？有了独立账本，这些问题都不用从总账里一条条挑出来。

## 循环交易

循环交易功能可帮你自动记录工资、房租、水电等固定收支。这类每期都会发生、金额大致稳定的项目，最适合交给应用自动生成，省得每月手动重复录入，也避免漏记。

### 添加循环交易

1. 从设置进入循环交易管理
2. 点击"添加循环交易"按钮
3. 选择交易类型（支出或收入）
4. 选择分类
5. 输入金额
6. 选择资产
7. 选择账本
8. 设定周期（每天、每周、每月、每年）
9. 设定开始与结束日期
10. 点击确认完成循环交易设置

![Recurring Add Category 主界面](/assets/images/blog/recurring_add_category_type.webp){: width="180" .normal } ![Recurring Add Category 主界面：选择](/assets/images/blog/recurring_add_category_select.webp){: width="180" .normal } ![Recurring Add 主界面](/assets/images/blog/recurring_add_assets.webp){: width="180" .normal } ![Recurring Add 主界面：账本](/assets/images/blog/recurring_add_ledger.webp){: width="180" .normal } ![Recurring Add 主界面：循环周期](/assets/images/blog/recurring_add_cycle.webp){: width="180" .normal }

设定时把周期和起止日期考虑清楚：房租按月、工资按月，起止日期则决定它从哪一期开始、到哪一期结束。支持同时选多个日期，适合那些一月内分几次扣的水电或订阅费。

### 循环交易管理

在循环交易列表中，你可以：
- 查看所有循环交易任务
- 编辑或删除循环交易任务
- 手动触发循环交易

![Recurring 主界面](/assets/images/blog/recurring_manage.webp){: width="180" .normal } ![Recurring 主界面：编辑](/assets/images/blog/recurring_edit.webp){: width="180" .normal }

工资涨了、房租变了，记得回来编辑对应任务的金额；不再发生的订阅就删掉。"手动触发"适合提前记账的场景，比如这笔房租这周就要付，不想等到系统生成。

## 费用报销

费用报销功能可帮你追踪需报销的开销。垫付的差旅、请客户吃饭这类钱，严格来说也是你的支出，但企业随后会补给你——报销功能就是用来把"待收回"和"已收回"分开，别让垫付款一直挂在支出里。

### 添加报销记录

1. 添加支出记录时，勾选"报销"选项
2. 完成其他记账信息
3. 点击确认完成报销记录添加

![Meow Money Manager 主界面与账户总览：报销](/assets/images/blog/record_add_reimburse.webp){: width="180" .normal }

只需在记支出时多勾一个选项，应用就会把它归入待报销，不打断你原本的记账节奏。备注里写上事由（如"出差高铁"），报销时更容易核对。

### 报销管理

1. 从设置进入报销管理
2. 查看所有待报销与已报销记录
3. 点击一条报销记录，标记为已报销
4. 输入报销金额与报销日期
5. 选择报销方式（资产）
6. 点击确认完成报销

![Meow Money Manager 主界面与账户总览：管理](/assets/images/blog/reimburse_manage.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：退款](/assets/images/blog/reimburse_refund.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：编辑](/assets/images/blog/reimburse_edit.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：报销（2）](/assets/images/blog/reimburse_reimburse.webp){: width="180" .normal } ![Meow Money Manager 主界面与账户总览：完成](/assets/images/blog/reimburse_done.webp){: width="180" .normal }

钱到账后回来标记为已报销，并选择它进了哪张卡——这才是关键一步：它让你的资产和支出同时恢复真实。支持部分报销与全额报销，遇到只报一半的情况也能如实记录，不必为了图省事按全额填。

## 设置

Meow Money Manager 提供多种设置选项，帮你自定义应用功能。设置页看着条目不少，但大多数只需配置一次：先按自己的习惯定好主题、语言和货币，之后重点用备份与导出守护数据就行。

### 基础设置

1. 从底部导航栏进入设置页
2. 调整以下设置：
   - 主题设置（浅色、深色或跟随系统）
   - 语言设置
   - 货币符号设置
   - 一周起始日设置
   - 一月起始日设置

![App 主界面：深色模式](/assets/images/blog/setting_dark.webp){: width="180" .normal } ![App 主界面：语言](/assets/images/blog/setting_language.webp){: width="180" .normal } ![Setting Currency 主界面](/assets/images/blog/setting_currency_symbol.webp){: width="180" .normal } ![Setting Week 主界面](/assets/images/blog/setting_week_begin.webp){: width="180" .normal } ![Setting Month 主界面](/assets/images/blog/setting_month_begin.webp){: width="180" .normal }

货币符号决定记账时显示的币种符号，出差或用外币时可随时切换；一周、一月的起始日则影响统计的分段——按国内习惯多用周一为一周之始、1 日为当月之始，但你完全可以按自己的薪资周期来定。

### 隐私设置

1. 在设置页点击"隐私设置"
2. 开启或关闭指纹应用锁
3. 设置应用密码（如需）

![App 主界面：应用锁](/assets/images/blog/setting_lock.webp){: width="180" .normal } ![Setting Lock 主界面](/assets/images/blog/setting_lock_password.webp){: width="180" .normal }

记账数据涉及收入、存款这类敏感信息，如果手机常被家人同事拿去用，开启指纹或密码锁能避免别人随手翻开。数据本身仍只存在本机，应用锁只是多一道进门检查。

### 备份与恢复

1. 在设置页点击"备份与恢复"
2. 选择备份方式：
   - Google Drive
   - iCloud 备份（仅 iOS）
   - WebDAV 备份
3. 点击"立即备份"进行手动备份
4. 点击"恢复"从备份文件恢复数据

![App 主界面：备份](/assets/images/blog/setting_backup.webp){: width="180" .normal } ![Setting Backup 主界面](/assets/images/blog/setting_backup_backup.webp){: width="180" .normal } ![Setting Backup 主界面：恢复](/assets/images/blog/setting_backup_restore.webp){: width="180" .normal } ![Setting Backup Restore 主界面](/assets/images/blog/setting_backup_restore_done.webp){: width="180" .normal }

数据默认只在本机，所以备份这一步别省：Android 用 Google Drive 或 WebDAV，iOS 还可以用 iCloud。开启自动备份能防止忘记手动备份时丢数据；换机后装好应用，用"恢复"把备份拉回来即可。

### 导出数据

1. 在设置页点击"导出数据"
2. 选择导出时间范围
3. 选择导出格式（CSV）
4. 点击"导出"将数据导出到文件

![App 主界面：导出](/assets/images/blog/setting_export.webp){: width="180" .normal } ![Setting Export 主界面](/assets/images/blog/setting_export_confirm.webp){: width="180" .normal } ![Setting Export 主界面：等待](/assets/images/blog/setting_export_waiting.webp){: width="180" .normal } ![Setting Export 主界面：完成](/assets/images/blog/setting_export_done.webp){: width="180" .normal }

导出的 CSV 能用 Excel 或表格软件打开，适合做应用内图表做不到的深度分析，或作为一份自己掌控的长期存档。挑好时间范围再导出，比每次导全量再筛选省事得多。

## 常见问题

### Meow Money Manager 需要注册账号吗？
{:.faq-q}

不需要。数据完全本地存储，没有云端账号也能完整使用，仅备份时才会走 Google Drive、iCloud 或 WebDav。这也意味着你的记账数据不会因为某个账号服务变动而被牵连。

### 支持哪些语言？
{:.faq-q}

支持中文、英文、印尼语、泰语、葡萄牙语等多语言界面。在设置里即可切换，无需重装应用。

### 支持多币种记账吗？
{:.faq-q}

支持，内置 50+ 种货币符号，并可为旅行、工作、家庭分设独立账本。出国旅行时切换对应货币符号，账目就不会混淆。

### 记录的数据怎么导出？
{:.faq-q}

在「设置 → 导出数据」中选择时间范围与 CSV 格式即可导出到文件，用 Excel 查看或编辑；也可通过 iCloud / WebDav 备份还原。

### 如何修改已添加的记账记录？
{:.faq-q}

1. 在记账记录列表中找到要修改的记录
2. 点击该记录，在弹出页选择"编辑"
3. 修改相关信息
4. 点击确认完成修改

记错金额、选错分类都能这样改；改完统计会同步更新，不必手动重算。

### 如何删除记账记录？
{:.faq-q}

1. 在记账记录列表中找到要删除的记录
2. 长按该记录并选择"删除"
3. 确认删除操作

删除不可撤销，操作前确认确实记重了或记错了。

### 如何切换货币符号？
{:.faq-q}

1. 进入设置页
2. 点击"货币符号设置"
3. 选择需要的货币符号
4. 点击确认完成设置

### 如何设置应用锁？
{:.faq-q}

1. 进入设置页
2. 点击"隐私设置"
3. 开启"指纹锁"或"密码锁"
4. 按提示完成设置

### 如何备份数据？
{:.faq-q}

1. 进入设置页
2. 点击"备份与恢复"
3. 选择备份方式
4. 点击"立即备份"进行手动备份

建议定期备份，尤其是在换机或清理手机之前。
