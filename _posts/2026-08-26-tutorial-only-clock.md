## App Introduction

Only Clock is a beautiful **full-screen flip clock** for Android and iOS — turn any phone or tablet into a desk or nightstand clock.

**🕐 Flip Animation**
- A smooth page-flip transition as digits change (about 600 ms per digit)
- Multiple themes (e.g. Black, White, Sky)

**🪟 Widgets**
- 18 themed clock widgets plus clock-grid widgets (1x1, 2x1, 2x2, 4x1, 4x2, flat/split)

**🔊 White Noise**
- Built-in ambient sounds (same engine as the standalone white-noise app) to help you focus or sleep

**📅 Flexible Display**
- Toggle 12/24-hour, seconds, week and date

> Note: Only Clock itself has **no pomodoro/focus timer** — that lives in a separate sibling app. The clock's white noise just helps you concentrate.

## First-time Use

Open the app to the **full-screen flip clock**.

- The toolbar (top) gives quick access to settings, theme, sound and size
- The screen stays awake while the clock is showing

## 12/24-hour, Seconds, Date

1. Open **Settings**
2. Toggle:
   - **24-hour** (default on)
   - **Seconds** (default on)
   - **Week** (default off)
   - **Date** (default off)
   - **Flip background** mask (default on)

![Only Clock settings screenshot: 12/24: hour, Seconds, Date — Only Clock Official User Guide](/assets/images/blog/tutorial_clock_settings.webp){: width="180" .normal }

## Clock Widgets

1. Open **Settings → Widget**
2. Browse the **gallery** of 26 styles
3. Tap a style → the app shows the "long-press home to add" guide
4. Long-press your home/lock screen → Widgets → pick Only Clock → place it
5. The 4x2 flip widget has its own config (seconds / mask / week / date)

![Only Clock widget screenshot: Clock Widgets — Only Clock Official User Guide](/assets/images/blog/tutorial_clock_widget.webp){: width="180" .normal }

## White Noise

1. Open **Settings → White noise**
2. Pick a sound from the 2-column grid (some are premium)
3. Tap to play/stop

The clock shares the same sound engine as the standalone white-noise app.

![Only Clock noise screenshot: White Noise — Only Clock Official User Guide](/assets/images/blog/tutorial_clock_noise.webp){: width="180" .normal }

## Floating Clock

1. Enable the floating-clock switch in the home toolbar
2. Grant the overlay permission if asked
3. A clock overlay shows above other apps

## Spare Phone as a Clock

Because the screen stays awake (`FLAG_KEEP_SCREEN_ON`) and you can place widgets, an old phone or tablet works great as a dedicated desk/nightstand clock. Allow battery optimization to be ignored so it is not killed.

## Free vs Pro

- **Free** shows ads and gates some themes/fonts/sounds behind reward ads or purchase
- **Pro** removes ads and unlocks everything

## FAQ

### Is there a focus/pomodoro timer in Only Clock?
No. The focus timer is a separate app. Only Clock provides the flip clock, widgets and white noise.

### Does it keep the screen on?
Yes — the clock uses a keep-screen-on flag while displayed; for a nightstand use, also ignore battery optimization.

## Summary

Only Clock turns any device into a gorgeous flip-clock display with widgets and soothing white noise — free to start, with a Pro upgrade to remove ads and unlock all themes.
