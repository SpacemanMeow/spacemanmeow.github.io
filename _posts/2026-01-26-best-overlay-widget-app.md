An **overlay widget app** keeps controls and info above whatever you are doing. **Floating Assistant** is a **floating window** tool that layers assistive touch, a clock, and a system monitor over any app. Here's how overlay tools compare, plus what to use them for.

![Overlay widget](/assets/images/apps/floating-assistant/screen-overlay.webp)

## What an overlay widget needs

- **Draw over other apps** permission
- Draggable, always-on elements
- Works in fullscreen and games
- Low battery impact

Floating Assistant meets these with its three floating modules.

## Use cases

- **One-handed control** via assistive touch.
- **Glanceable clock** anywhere.
- **Live performance** while gaming via the floating monitor.
- **Quick app launch** without leaving the current app.

## How to choose by need

- Want **controls + clock + monitor** → **Floating Assistant**.
- Want **navigation buttons only** → Assistive Touch.
- Want **floating mini-apps** (notes, browser) → Floating Apps.
- Want a **custom quick menu** → Floating Menu.
