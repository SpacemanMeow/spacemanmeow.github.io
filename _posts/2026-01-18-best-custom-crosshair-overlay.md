A **custom crosshair overlay** helps you aim in shooters that hide or lack a reticle. **Crosshair Aim** draws a tunable crosshair over any game without modifying it. Here's how overlays compare, plus how to tune one well.

![Custom crosshair overlay](/assets/images/apps/cross-hair/screen-custom.webp)

## What a custom crosshair needs

- **Style choice** (dot, cross, circle, and more)
- **Size, color, position** control
- **Transparency** so it does not block view
- **No-root overlay** safety

Crosshair Aim covers all four.

## Tune it to your game

1. Pick a base style (dot for precision, cross for tracking).
2. Set **color** for contrast (white on dark maps, red on bright).
3. Set **size** so it sits where your eye naturally centers.
4. Lower **opacity** if it blocks the HUD; adjust in-game with the floating tool.

## Safety and fair use

- A no-root overlay **only draws on screen** — it cannot alter hit registration or game data.
- Use it as an **accessibility/aiming aid**, not a cheat; respect each game's rules.
