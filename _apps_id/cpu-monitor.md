CPU Monitor adalah pemantau perangkat keras untuk Android. Ia menampilkan suhu dan frekuensi prosesor secara langsung, menganalisis riwayatnya, dan mendukung pemantauan CPU multi-inti. Seluruh angka berasal dari sensor sistem perangkat Anda.

### Fitur CPU Monitor

**Suhu dan frekuensi CPU secara langsung**

Pantau suhu CPU dan frekuensinya secara langsung, analisis data riwayat, dan dukung pemantauan CPU multi-inti.

**One Tap Boost**

Buat pintasan One Tap Boost untuk membebaskan RAM dengan sekali ketuk.

**Alarm suhu berlebih**

CPU Monitor membunyikan alarm saat suhu CPU atau baterai terlalu panas; alarm ini dapat diaktifkan atau dimatikan sesuai keinginan.

**Jendela mengambang**

Jendela mengambang menampilkan suhu CPU, suhu baterai, dan penggunaan RAM secara langsung, baik di bilah status maupun di layar utama.

**Widget**

Tersedia widget RAM, widget CPU, dan widget baterai.

**Beragam tema**

CPU Monitor mendukung pergantian multi-tema, sehingga Anda bisa memilih tampilan yang disukai.
