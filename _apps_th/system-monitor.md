System Monitor คือเครื่องมือข้อมูลฮาร์ดแวร์สำหรับ Android มันแสดงสภาพ CPU RAM พื้นที่จัดเก็บ และแบตเตอรี่ในแดชบอร์ดเดียว **ที่ต้องเน้นย้ำ: แอปนี้เป็นแบบอ่านอย่างเดียว** — มันแสดงข้อมูล แต่ไม่ลบไฟล์ ไม่ทำความสะอาด junk และไม่เคลียร์ RAM

### ฟีเจอร์ System Monitor

**ตัวตรวจสอบ CPU**

ตรวจสอบอุณหภูมิและความถี่ CPU เรียลไทม์ในรูปเส้นโค้ง แล้ววิเคราะห์ประวัติอุณหภูมิและความถี่เพื่อดูรูปแบบประสิทธิภาพ

**ข้อมูลพื้นที่จัดเก็บ**

ดูการใช้พื้นที่จัดเก็บ: พื้นที่ใช้ไป พื้นที่ว่าง และอะไรกันที่กินมัน นี่คือข้อมูลอ่านอย่างเดียว; System Monitor ไม่ลบไฟล์หรือทำความสะอาด junk

**ข้อมูลหน่วยความจำ**

ดูการใช้ RAM และการใช้หน่วยความจำต่อแอปเหลียวเดียว นี่คือข้อมูลอ่านอย่างเดียว; System Monitor ไม่เคลียร์หรือเพิ่ม RAM

**ตัวตรวจสอบแบตเตอรี่**

แสดงเส้นโค้งการใช้และอุณหภูมิแบตเตอรี่ ตรวจสอบสถานะแบตเตอรี่ รวมสุขภาพ สถานะพลังงาน แรงดัน และระดับ

**ตัวประหยัดและดูแลแบตเตอรี่**

ยืดอายุแบตเตอรี่ด้วยการปรับแต่งการตั้งค่าอุปกรณ์; มีโหมด LONG LIFE MODE และ CUSTOM SAVE MODE

**การเตือนและป้องกันความร้อนเกิน**

System Monitor ดังการเตือนเมื่ออุณหภูมิ CPU หรือแบตเตอรี่ร้อนเกินไป การเตือนสามารถเปิดหรือปิดได้ตามต้องการ

**หน้าต่างลอย**

หน้าต่างลอยแสดงอุณหภูมิ CPU อุณหภูมิแบตเตอรี่ และการใช้ RAM เรียลไทม์ ทั้งในแถบสถานะและบนหน้าจอหลัก

**วิดเจ็ต**

มีวิดเจ็ต RAM วิดเจ็ต CPU และวิดเจ็ตแบตเตอรี่

**ธีมหลากหลาย**

System Monitor สนับสนุนการสลับมัลติธีม จึงคุณเลือกมุมมองที่ชอบได้
