CPU Monitor คือตัวตรวจสอบฮาร์ดแวร์สำหรับ Android มันแสดงอุณหภูมิและความถี่โปรเซสเซอร์เรียลไทม์ วิเคราะห์ประวัติ และสนับสนุนการตรวจสอบ CPU มัลติคอร์ ตัวเลขทั้งหมดมาจากเซ็นเซอร์ระบบของอุปกรณ์คุณ

### ฟีเจอร์ CPU Monitor

**อุณหภูมิและความถี่ CPU เรียลไทม์**

ตรวจสอบอุณหภูมิ CPU และความถี่ของมันเรียลไทม์ วิเคราะห์ข้อมูลประวัติ และสนับสนุนการตรวจสอบ CPU มัลติคอร์

**One Tap Boost**

สร้างทางลัด One Tap Boost เพื่อปลด RAM ด้วยการแตะเดียว

**การเตือนความร้อนเกิน**

CPU Monitor ดังการเตือนเมื่ออุณหภูมิ CPU หรือแบตเตอรี่ร้อนเกินไป; การเตือนนี้เปิดหรือปิดได้ตามต้องการ

**หน้าต่างลอย**

หน้าต่างลอยแสดงอุณหภูมิ CPU อุณหภูมิแบตเตอรี่ และการใช้งาน RAM เรียลไทม์ ทั้งในแถบสถานะและบนหน้าจอหลัก

**วิดเจ็ต**

มีวิดเจ็ต RAM วิดเจ็ต CPU และวิดเจ็ตแบตเตอรี่

**ธีมหลากหลาย**

CPU Monitor สนับสนุนการสลับมัลติธีม จึงคุณเลือกมุมมองที่ชอบได้
