## นิยามและวิธีการทำงาน

**ตัวตรวจสอบอุณหภูมิ CPU** อ่านเซ็นเซอร์ความร้อนบนอุปกรณ์ Android และแสดงอุณหภูมิ ความถี่ และภาระของแต่ละคอร์โปรเซสเซอร์

## สิ่งที่มันทำ

- แสดงอุณหภูมิแบตเตอรี่และโปรเซสเซอร์เป็นระยะ
- ตรวจสอบความถี่และการใช้งานต่อคอร์ CPU
- เก็บประวัติและแจ้งเตือนเมื่ออุณหภูมิสูง

## ทำไมจึงมีประโยชน์

ความร้อนเกินลดประสิทธิภาพและทำให้โทรศัพท์จับไม่สบายมือ ข้อมูลอุณหภูมิช่วยแยกความร้อนปกติขณะชาร์จออกจากความร้อนจากภาระหนัก CPU Monitor แสดงตัวเลขจากเซ็นเซอร์ระบบในโหมดอ่านอย่างเดียว ไม่แก้ไขระบบและไม่ต้อง root
