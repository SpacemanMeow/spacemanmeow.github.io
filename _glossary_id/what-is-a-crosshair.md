## Definisi & Cara Kerja

**Crosshair** adalah tanda bidik berbentuk silang atau titik yang ditampilkan di tengah layar untuk membantu membidik dalam game FPS.

## Apa yang dilakukannya

- Menambahkan tanda bidik pada game yang tidak menyediakannya.
- Mengatur ukuran, warna, posisi, dan transparansi tanda.
- Menyimpan preset terpisah untuk tiap game.

## Mengapa berguna

Sebagian senjata dalam game mobile tidak punya tanda bidik bawaan, sehingga pemain kesulitan membidik. Overlay murni visual seperti Crosshair Aim hanya menggambar di atas layar: tidak mengubah data game, tidak memodifikasi memori, dan tidak memerlukan root.
