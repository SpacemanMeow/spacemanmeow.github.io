## 定义与三星设计

**Galaxy One UI** 是三星在 Galaxy 手机、平板与手表上叠在安卓之上的定制界面。它用圆角卡片、沉静的配色系统，以及为「易触达」而重排的布局——把主要操作放在屏幕下半部，让高屏手机也能轻松点按。

## 核心理念

- **单手优先**：主操作落在拇指自然可及之处。
- **柔和圆角卡片**：系统与应用一以贯之的视觉语言。
- **深度设备集成**：电池、内存、设备维护组件都像原生一样自然。

## 小组件为何采用它

三星用户期待那种精致、协调的三星质感，所以组件包会提供 Galaxy One UI 风格组件——圆润、环境感、并与系统主题同色。One Widget 提供高度还原、专为 Galaxy 设备优化的 One UI 风格，让主屏与手机自身 UI 融为一体，而非彼此冲突。
