## Definition & Samsung Design

**Galaxy One UI** is the custom interface Samsung lays over Android on its Galaxy phones, tablets, and watches. It reshapes Google's base look with rounded cards, a calm color system, and a layout tuned for reachability — placing key controls in the lower half of the screen so they're easy to tap on tall devices.

## Key ideas

- **Reachability first:** primary actions sit where your thumb naturally lands.
- **Soft, rounded cards:** a consistent visual language across system and apps.
- **Deep device integration:** battery, RAM, and device-care widgets feel native.

## Why widgets adopt it

Samsung users expect that polished, cohesive Samsung feel, so widget packs ship Galaxy One UI-style widgets — rounded, ambient, and color-matched to the system theme. One Widget offers a highly restored Galaxy One UI style optimized for Galaxy devices, so the home screen blends with the phone's own UI instead of clashing with it.
