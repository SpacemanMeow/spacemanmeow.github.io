A **crosshair** is the aiming reticle—usually a small cross, dot, or ring—centered on a screen to mark where actions or shots land. On desktops it is built into games; on phones it often is not.

## Why mobile gamers add one

- **Precision:** a fixed center reference helps aim in shooters and FPS titles.
- **Consistency:** an overlay stays put regardless of in-game UI changes.
- **Low distraction:** a thin, adjustable reticle is easier to read than busy default markers.

## How a crosshair overlay works

An app like CrossHair draws a transparent, always-on-top layer with a customizable crosshair (color, size, shape) that follows a fixed screen position. It does not touch the game—it simply renders a reference on top. Players tune opacity and offset so the reticle sits exactly where they want, then leave it running only while gaming.
