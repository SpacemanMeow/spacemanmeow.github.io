一款只读的 CPU、内存与电池系统监控器。你可同时监控 CPU 温度、CPU 频率、存储使用率、内存使用率、电池温度与电池健康——全部只读，不清理也不加速。System Monitor 还提供过热警报、过热保护、内存/CPU/电池小组件与悬浮窗，让你看清手机内部的真实状况。

### 只读监控：看清真实状况，不做加速噱头

System Monitor 的定位是"仪表盘"而不是"清理大师"。它把 CPU、存储、内存与电池的真实读数摆在你面前，但不删除文件、不清缓存，也不释放或加速内存。这一点很重要：如果你想要的是一键清理，它并不提供；如果你想要的是可信的数据，它不会用虚高的"加速结果"误导你。

### CPU 与多核：温度、频率与曲线

实时监控 CPU 温度与频率，并以曲线表展示，支持分析历史数据与多核监控。曲线比单个数字更说明问题：你能看出温度是缓慢爬升还是突然飙升，也能发现是否某一颗核心长期满载，从而判断卡顿是否与发热降频有关。

### 存储与内存：查看占用，不动你的文件

- 存储信息：查看已用、可用空间与占用情况；这是只读信息，不会删除文件或清理缓存。
- 内存信息：一眼查看 RAM 使用率与各应用内存占用；这也是只读信息，不会释放或加速内存。

### 电池监控与省电模式

显示电池使用率与温度的曲线，并监控健康、电源状态、电压与电量。想延长续航，可以在「长效模式」与「自定义省电模式」之间选择，通过优化设备设置来减少耗电。

### 过热警报、悬浮窗与小组件

当 CPU 或电池温度过高时触发警报（可自行开启或关闭），并提供过热保护。悬浮窗实时显示 CPU 温度、电池温度与内存使用率，含状态栏悬浮窗与桌面悬浮窗；小组件则支持内存、CPU 与电池三种。界面精美，支持多主题切换。

### 适合谁用、取舍与常见疑问

适合想了解手机真实状态、关心电池健康、又反感"内存加速"套路的用户：排查发热、判断是否该换机、看清空间都被谁占了，都能用上。它是一次性付费下载，没有订阅，也没有内存加速噱头——如果你只想免费看个温度，可以先考虑同类免费工具；如果你希望一个应用把 CPU、存储、内存、电池都讲清楚，它更省事。

- **能清理垃圾或加速内存吗？** 不能，它是只读监控工具。
- **会监控电池健康吗？** 会，连同温度、电压、电量与电源状态一起看。
- **有过热警报吗？** 有，并可按需开关。
