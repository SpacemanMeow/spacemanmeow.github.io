### System Monitor 功能特性 - 完整指南

**CPU 监控**

实时监控 CPU 温度与频率，并以曲线表展示，分析温度与频率历史数据，支持多核 CPU 监控，帮助你了解 CPU 使用率、发现性能问题（如同手机降温器所报告的那样）。

**存储信息**

查看存储使用率——已用空间、可用空间及占用情况。这是只读信息，System Monitor 不会删除文件或清理缓存。

**内存信息**

一眼查看内存（RAM）使用率与各应用内存占用。这是只读信息，System Monitor 不会释放或加速内存。

**电池监控**

显示电池使用率与温度的曲线表，监控电池状态，包括：健康、电源状态、电压、电量。

**电池省电与医生**

通过优化设备设置延长电池寿命，可选择「长效模式」或「自定义省电模式」。

**温度过高过热警报与过热保护**

当 CPU 或电池温度过高时，System Monitor 会触发警报，你可自行开启或关闭过热警报。

**悬浮窗**

悬浮窗实时显示 CPU 温度、电池温度与内存使用率，包括状态栏悬浮窗与桌面悬浮窗。

**小组件**

支持内存小组件、CPU 小组件与电池小组件。

**多主题**

强大的 System Monitor 界面精美，支持多主题切换，你可选择喜欢的主题。
