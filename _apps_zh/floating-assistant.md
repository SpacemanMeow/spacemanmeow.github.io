Floating Assistant 包含：辅助触控、悬浮时钟与悬浮监控。辅助触控让你更快捷地访问常用应用、设置并快速切换，也更适合用于替代主页与音量按键，保护实体按键。悬浮时钟在悬浮窗中显示时间与倒计时，方便你在使用其他应用时查看时间。悬浮监控显示 CPU 温度与使用率、内存使用率，并可一键清理内存。

**辅助触控**

辅助触控是 Android 设备上的便捷工具。屏幕上的悬浮窗让你轻松使用智能手机，快速访问常用应用、游戏、设置与快捷开关；使用智能清理功能清理后台运行的应用，让手机更流畅。辅助触控能保护主页键、音量键等实体按键，对大屏手机尤为实用。

- 虚拟主页键
- 虚拟返回键
- 虚拟多任务键
- 虚拟音量键，轻触即可调节音量并切换声音模式
- 一键加速、清理内存、提升速度
- 一键锁屏
- 一键拨打电话
- 截屏
- 手电筒高亮
- 屏幕旋转
- 自动亮度
- 轻触快速打开常用应用
- 一键直达所有设置

**悬浮时钟与倒计时**

悬浮于其他应用之上，适合全屏应用。它是绘制在所有应用之上的数字时钟，可在全屏应用中使用。

- 拖动调整时钟在屏幕上的位置
- 支持 24 小时制或显示秒
- 可保存时钟位置
- 显示/隐藏秒
- 不同时长的倒计时

**悬浮监控**

悬浮窗实时显示 CPU 温度、电池温度与内存使用率，全屏游戏时尤为实用，可监控 CPU、内存与电池状态，一键加速让游戏更流畅快速。

- 实时监控 CPU 温度、频率与使用率，并以曲线展示
- 分析内存使用率、清理内存、加速手机
- 显示电池电量
- 一键加速、清理内存、提升速度

**如何使用**

- 打开 Floating Assistant 应用
- 授予「在其他应用上层显示」权限
- 授予无障碍权限
- 自定义常用快捷键、悬浮球外观与操作
- 畅享对所有设置的快速访问，轻松操控设备

**本应用的无障碍服务用于以下功能**

- 锁屏
- 返回主页
- 打开多任务
- 返回
- 截屏
- 调用相机开启手电筒（不拍照）
