Meow Money Manager 记账本是一款个人财务管理应用，助你掌控预算、资金与财务状况。开支与收入追踪让钱包与每张信用卡都清晰明了。你无需翻找钱包或查询银行账户就能掌握财务情况。用这款预算开支收入追踪财务应用，轻松管理你的资金。

### Meow Money Manager 功能特性 - 完整指南

**可爱的记账分类图标**

400+ 可爱图标供你自定义专属记账本。Meow Money Manager 提供多种记录类型，你可以为消费习惯挑选图标。

**预算追踪与分类预算**

可设置每日、每月或每年的预算。你还能为任意支出或收入类别设置分类预算，总预算与所有分类预算将同时清晰追踪。

**即时强大的图表统计**

按日、月、年生成财务记录报表，让你更轻松地掌握财务状况。

**报销管理**

当支出需要报销（如出差）时，只需在添加记录页勾选报销按钮，Meow Manager 便会自动追踪报销状态，你可随时查看与修改。

**支持多账本**

你可添加不同账本以追踪不同收支，并分别查看每个账本的记录，也可同时选择单个或全部账本。

**资产管理**

你可添加现金、基金、股票、银行卡等多种资产，Meow Manager 会追踪你的资产、负债与净资产。

**循环记录**

Meow Manager 支持循环记录，可设置循环记录类别与周期（每日、每周、每月、每年），到时自动记录。

**深色模式**

可选择深色、浅色主题，或自动跟随系统主题，随心切换。

**货币符号**

Meow Money Manager 支持 50+ 种货币符号，包括：美元、人民币、英镑、欧元、法郎、卢布、卢比、里拉等。

**指纹应用锁**

可设置指纹应用锁保护隐私，打开应用时需验证指纹。

**导出报表**

Meow Manager 可将记录报表导出为 CSV 文件，可一次性导出全部记录，也可导出所选时间范围内的记录，再用 Excel 查看编辑。

**备份与恢复**

Meow Money Manager 支持 iCloud 与 WebDav 备份，添加记录时自动保存备份文件以防数据丢失，也支持手动备份。
