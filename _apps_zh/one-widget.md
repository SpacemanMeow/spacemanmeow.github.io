One Widget 是一款 Android 桌面组件工具，内置 500+ 款预设组件，覆盖四种设计风格：Glass iOS 风格、Material You、Galaxy One UI（三星）与 Nothing 极简风格。它适合希望统一桌面风格、又不想从零制作组件的用户，选一个预设即可放到主屏。

### 四种流行小组件风格

无需安装多个小组件应用！我们把主流设计风格集于一身：

- **Glass iOS 风格**：还原通透磨砂的 iOS 视觉效果，呈现利落的模糊美感
- **Material You**：动态风格随系统壁纸颜色自适应，契合纯 Android 原生美学
- **Galaxy One UI**：高度还原，专为三星 Galaxy 设备优化，细节贴合官方 UI
- **Nothing 极简**：低饱和度、未来感桌面视觉，带来纯粹整洁的主屏

### 8 大功能小组件类别

1. **应用快捷方式**：1x1、1x2、2x2、1x4、1x5、1x6、2x4、2x5、2x6 等多尺寸布局，可自定义图标背景色与圆角。
2. **系统快捷开关**：一键控制 Wi-Fi、移动数据、蓝牙、手电筒、屏幕旋转、飞行模式、热点、勿扰、定位、振动模式与深色模式。
3. **设备硬件信息**：实时显示电量、详细电池状态、内存使用率与内部存储数据。
4. **时钟与日历**：多种时尚数字时钟搭配实用日历，掌握时间与日程。
5. **备忘与语录**：备忘录清单与灵感语录组件，适合每日待办提醒与情绪调节。
6. **快捷联系人**：把常用联系人放上桌面，一键拨号与访问。
7. **聚合应用**：Google 套件（Chrome、Drive、地图、相册、Play、YouTube、邮箱、日历）、AI 工具包（Claude、Copilot、Gemini、GPT、Grok、Perplexity）与社交套件（Facebook、Instagram、LinkedIn、Snapchat、Telegram、TikTok、WhatsApp、X）。
8. **迷你工具**：指南针、计步器、计数器与计算器，无需额外安装应用。

### 尺寸与自定义：从 1x1 到 2x6

每款小组件都能按桌面空间调整尺寸，从 1x1 的小图标到 2x6 的大面板都有；图标背景色与圆角也可以自定义，方便和壁纸、主题配色对齐。想留白就放 1x1，想一眼看全信息就放 2x6——同一套组件能适配不同桌面布局。

### 适合谁用：设备支持与一站式取舍

One Widget 适用于所有 Android 设备，包括三星 Galaxy、Google Pixel 与 Nothing 手机。适合喜欢桌面美化、希望常用开关和应用触手可及的人。取舍在于：与其分别装多个风格各异的小组件应用，不如在一个应用里挑齐 500+ 组件；代价是部分风格需要付费解锁，免费版先给到 One UI 主题组件，够你先试出手感。

### 免费版与付费、常见疑问

One Widget 是付费应用：免费版包含 One UI 主题小组件，Glass、Material You 与 Nothing 等风格需购买解锁，组件还会持续更新添加。

- **支持哪些风格？** Glass iOS、Material You、Galaxy One UI 与 Nothing 四大风格。
- **能添加快捷开关吗？** 能，Wi-Fi、蓝牙、手电筒等系统开关，以及应用快捷方式、联系人与 AI 工具启动器都可添加。
- **自定义程度如何？** 尺寸 1x1 到 2x6、图标背景色与圆角都能调。
