CPU Monitor 是一款安卓设备监控工具，可实时显示 CPU 温度与频率，并保留历史数据供回看。CPU Monitor 还提供多种实用工具，包括内存小组件、CPU 小组件、电池小组件、桌面悬浮窗与过热警报，让你随时掌握内存、CPU 与电池信息。

### 它能看到什么：CPU、GPU、内存与电池

CPU Monitor 把手机内部的关键读数集中到一处：CPU 温度与频率、多核使用情况、GPU 温度、内存使用率以及电池状态。数据实时刷新，不需要反复切换系统设置页。GPU 温度还能用温度曲线呈现，打游戏或看视频时设备究竟有多热，一眼就能看出来。

### 温度曲线与历史分析

除了"此刻多少度"，应用还会记录温度与频率的历史：回到某个时间点回看曲线，你能判断是刚开机就热，还是玩了半小时后才升温。配合多核监控，可以观察是不是某一颗核心长期满载，帮助发现性能异常。

### 过热警报：发现发热及时处理

当 CPU 或电池温度过高时，CPU Monitor 会触发警报，你也可以按需要开启或关闭这个功能。收到提醒后，关掉高负载应用、取下厚重手机壳或暂停充电，都是常见的降温办法。需要强调的是：它是监控与提醒工具，真正降温靠的是你据此做的操作。

### 悬浮窗与小组件：随时盯住状态

- 状态栏悬浮窗与桌面悬浮窗，实时显示 CPU 温度、电池温度与内存使用率
- 内存小组件、CPU 小组件与电池小组件，放在桌面即可随手看到关键读数
- 多主题切换，界面精美，可按喜好挑选

### 适合谁用：游戏、视频与充电场景

- 长时间打游戏，担心手机发烫降频的玩家
- 用手机连续看视频或导航，想知道设备负载的人
- 充电时发现机身很热，想确认是否异常的用户
- 喜欢折腾、想排查性能问题的进阶用户

### 取舍建议与常见疑问

- **它能给手机降温吗？** 它负责显示温度并在过热时报警，不直接降温；你需要根据提醒关掉高负载应用或让设备休息。
- **支持多核吗？** 支持，可实时查看多核使用率与频率，并分析历史。
- **需要一直开着吗？** 不必。想监测时开悬浮窗或小组件，平时关掉即可，按自己的使用节奏来。
