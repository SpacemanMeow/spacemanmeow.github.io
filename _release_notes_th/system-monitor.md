## 11.11.1

1. เพิ่มหน้าต่างลอยเซ็นเซอร์ใหม่ 8 รายการ
    - เครื่องวัดความเร่ง
    - ไจโรสโคป
    - เซ็นเซอร์สนามแม่เหล็ก
    - เซ็นเซอร์แรงโน้มถ่วง
    - เซ็นเซอร์ความเร่งเชิงเส้น
    - เวกเตอร์การหมุน
    - เซ็นเซอร์แสง
    - เซ็นเซอร์ความดัน

## 11.10.8

1. เพิ่มฟังก์ชันเปิดหน้าต่างลอยล่าสุดขึ้นมาใหม่โดยอัตโนมัติ
2. เพิ่มการรองรับภาษาเยอรมัน เกาหลี และเวียดนาม
3. ปรับปรุงการใช้หน่วยความจำและประสิทธิภาพ
4. แก้ไขปัญหาและข้อขัดข้องที่ทราบแล้ว

## 11.10.7

1. เพิ่มรูปแบบหน้าต่างลอยหลายแบบ
2. แก้ไขตำแหน่งการแสดงผลหน้าต่างลอยที่ผิดปกติในโหมดแนวนอน
3. เพิ่มการตั้งค่าความถี่ในการรีเฟรชข้อมูลแบบกำหนดเอง
4. แก้ไขปัญหาและข้อขัดข้องที่ทราบแล้วบางส่วน

## 11.10.6

1. การอัปเดตครั้งสำคัญ:
2. เพิ่มวิดเจ็ตเดสก์ท็อปหลายแบบ
3. แก้ไขปัญหาที่ทราบแล้ว

## 11.10.5

1. ปรับปรุงการแสดงกราฟอุณหภูมิ CPU
2. แก้ไขการแสดงเปอร์เซ็นต์การใช้งาน CPU ที่ไม่ถูกต้อง
3. ปรับปรุงหน้าแนะนำการขอสิทธิ์หน้าต่างลอย
4. อัปเกรดเป้าหมาย API เป็น API 36

## 11.10.4

1. ปรับปรุงประสิทธิภาพการโหลดไอคอนและชื่อแอป แก้ไขอาการกระตุกเมื่อเลื่อนรายการ
2. ปรับปรุงหน้าจอแนะนำวิธีแก้ไขเมื่อหน้าต่างลอยปิดตัวลงโดยผิดปกติ
3. แก้ไขปัญหาออนไลน์และข้อขัดข้องที่ทราบแล้ว
