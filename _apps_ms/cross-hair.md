Crosshair Aim Pro ialah aplikasi overlay [crosshair](/ms/glossary/what-is-a-crosshair/) untuk game FPS di Android dengan lebih daripada 80 reka bentuk tanda bidik. Aplikasi ini menambahkan penunjuk virtual yang boleh disesuaikan pada kawalan senjata — ukuran, warna, dan posisi boleh diatur — supaya anda boleh menukar crosshair dalam apa-apa game penembakan dan membidik sasaran dengan lebih tepat. Ia turut menjana crosshair tersuai untuk senjata yang tidak menyediakan tanda bidik bawaan, dan menyokong hampir semua judul FPS popular. Gaya asas percuma; gaya lanjutan dan premium memerlukan pembelian versi pro.

### Ciri Crosshair Aim Pro

**Beragam reka bentuk crosshair**

Pilih dari koleksi reka bentuk crosshair yang luas untuk ditambahkan sebagai overlay pada game FPS, sehingga bidikan menjadi lebih presisi dan tepat.

**Sesuaikan crosshair untuk game FPS Anda**

Ubah reka bentuk crosshair menurut game yang dimainkan. Bosan dengan tanda bidik bawaan? Ganti crosshair game apa pun dan atur ukuran serta posisinya supaya pas dengan kontrol senjata.

**Buat crosshair untuk senjata yang tidak mendukungnya**

Crosshair Aim Pro menghasilkan crosshair tersuai untuk senjata yang tidak menyediakan tanda bidik, membantu Anda membidik sasaran dengan lebih tepat.

**Mendukung berbagai game**

Crosshair Aim mendukung hampir semua game penembakan FPS popular untuk menukar reka bentuk crosshair bawaannya, termasuk beragam judul game aksi utama.
