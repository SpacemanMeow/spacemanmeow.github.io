System Monitor adalah alat maklumat peranti keras untuk Android. Ia memaparkan kondisi CPU, RAM, storan, dan bateri dalam satu papan pemuka. **Yang perlu ditegaskan: aplikasi ini bersifat baca sahaja** — ia memaparkan data, tetapi tidak memadam fail, tidak membersihkan sampah, dan tidak membebaskan RAM.

### Ciri System Monitor

**Pemantau CPU**

Pantau suhu dan frekuensi CPU secara masa nyata dalam bentuk lengkung, lalu analisis sejarah suhu dan frekuensi untuk melihat pola prestasi.

**Maklumat storan**

Lihat penggunaan storan: ruang terpakai, ruang kosong, dan apa yang memakainya. Ini maklumat baca sahaja; System Monitor tidak memadam fail atau membersihkan sampah.

**Maklumat memori**

Lihat penggunaan RAM dan penggunaan memori per aplikasi sekilas. Ini maklumat baca sahaja; System Monitor tidak membebaskan atau menambah RAM.

**Pemantau bateri**

Tampilkan lengkung penggunaan dan suhu bateri. Pantau status bateri, termasuk kesihatan, status daya, voltase, dan level.

**Penghemat dan perawat bateri**

Perpanjang usia bateri dengan mengoptimalkan tetapan peranti; tersedia mode LONG LIFE MODE dan CUSTOM SAVE MODE.

**Penggera dan perlindungan panas berlebih**

System Monitor membunyikan penggera saat suhu CPU atau bateri terlalu panas. Penggera dapat diaktifkan atau dimatikan mengikut keperluan.

**Tetingkap terapung**

Tetingkap terapung memaparkan suhu CPU, suhu bateri, dan penggunaan RAM secara masa nyata, baik di bar status maupun di skrin utama.

**Widget**

Tersedia widget RAM, widget CPU, dan widget bateri.

**Beragam tema**

System Monitor mendukung pergantian multi-tema, sehingga Anda dapat memilih paparan yang disukai.
