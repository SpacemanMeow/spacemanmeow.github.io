System Monitor ialah alat maklumat perkakasan Android berbayar satu kali yang memaparkan suhu dan frekuensi CPU, penggunaan RAM, storan, serta kesihatan bateri dalam satu papan pemuka. Yang perlu ditegaskan: aplikasi ini bersifat baca sahaja — ia memaparkan data tetapi tidak memadam fail, tidak membersihkan sampah, dan tidak membebaskan RAM. Bacaan suhu dan frekuensi CPU dipaparkan dalam bentuk lengkung bersama sejarah, maklumat memori menunjukkan penggunaan per aplikasi, dan pemantau bateri merangkumi kesihatan, status daya, voltase, serta level. Penggera panas berlebih, tetingkap terapung, widget RAM/CPU/bateri, dan multi-tema melengkapkan ciri-cirinya, dengan dua mod penjimatan bateri, LONG LIFE MODE dan CUSTOM SAVE MODE.

### Ciri System Monitor

**Pemantau CPU**

Pantau suhu dan frekuensi CPU secara masa nyata dalam bentuk lengkung, lalu analisis sejarah suhu dan frekuensi untuk melihat pola prestasi.

**Maklumat storan**

Lihat penggunaan storan: ruang terpakai, ruang kosong, dan apa yang memakainya. Ini maklumat baca sahaja; System Monitor tidak memadam fail atau membersihkan sampah.

**Maklumat memori**

Lihat penggunaan RAM dan penggunaan memori per aplikasi sekilas. Ini maklumat baca sahaja; System Monitor tidak membebaskan atau menambah RAM.

**Pemantau bateri**

Tampilkan lengkung penggunaan dan suhu bateri. Pantau status bateri, termasuk kesihatan, status daya, voltase, dan level.

**Penghemat dan perawat bateri**

Perpanjang usia bateri dengan mengoptimalkan tetapan peranti; tersedia mode LONG LIFE MODE dan CUSTOM SAVE MODE.

**Penggera dan perlindungan panas berlebih**

System Monitor membunyikan penggera saat suhu CPU atau bateri terlalu panas. Penggera dapat diaktifkan atau dimatikan mengikut keperluan.

**Tetingkap terapung**

Tetingkap terapung pada skrin utama memaparkan suhu CPU, suhu GPU, tahap dan suhu bateri, penggunaan RAM, serta bacaan lapan sensor (pecutan, giroskop, medan magnet, graviti, pecutan linear, vektor putaran, cahaya, tekanan). Tiada paparan pada bar status; semua tetingkap boleh digerak dan diubah saiznya.

**Widget**

Tersedia widget RAM, widget CPU, dan widget bateri.

**Beragam tema**

System Monitor mendukung pergantian multi-tema, sehingga Anda dapat memilih paparan yang disukai.
