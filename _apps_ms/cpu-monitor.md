CPU Monitor adalah pemantau peranti keras untuk Android. Ia memaparkan suhu dan frekuensi pemproses secara masa nyata, menganalisis riwayatnya, dan mendukung pemantauan CPU multi-inti. Seluruh angka berasal dari sensor sistem peranti Anda.

### Ciri CPU Monitor

**Suhu dan frekuensi CPU secara masa nyata**

Pantau suhu CPU dan frekuensinya secara masa nyata, analisis data sejarah, dan dukung pemantauan CPU multi-inti.

**One Tap Boost**

Buat pintasan One Tap Boost untuk membebaskan RAM dengan sekali ketik.

**Penggera suhu berlebih**

CPU Monitor membunyikan penggera saat suhu CPU atau bateri terlalu panas; penggera ini dapat diaktifkan atau dimatikan sesuai keinginan.

**Tetingkap terapung**

Tetingkap terapung memaparkan suhu CPU, suhu bateri, dan penggunaan RAM secara masa nyata, baik di bar status maupun di skrin utama.

**Widget**

Tersedia widget RAM, widget CPU, dan widget bateri.

**Beragam tema**

CPU Monitor mendukung pergantian multi-tema, sehingga Anda boleh memilih paparan yang disukai.
