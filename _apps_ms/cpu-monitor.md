CPU Monitor ialah pemantau perkakasan Android yang memaparkan suhu dan frekuensi pemproses secara masa nyata, menganalisis sejarah bacaan, dan menyokong pemantauan CPU multi-inti. Aplikasi ini turut memantau suhu GPU, RAM, dan bateri, dengan penggera panas berlebih yang boleh diaktifkan atau dimatikan, tetingkap terapung di bar status dan skrin utama, serta widget RAM, CPU, dan bateri. Multi-tema tersedia supaya paparan boleh disesuaikan. Seluruh angka berasal terus daripada sensor sistem peranti, jadi bacaan suhu dan frekuensi mencerminkan keadaan sebenar telefon pintar semasa gaming, mengecas, atau menjalankan aplikasi berat.

### Ciri CPU Monitor

**Suhu dan frekuensi CPU secara masa nyata**

Pantau suhu CPU dan frekuensinya secara masa nyata, analisis data sejarah, dan dukung pemantauan CPU multi-inti.

**Suhu GPU secara masa nyata**

Pantau suhu GPU secara masa nyata dan ikuti lengkung suhunya untuk melihat seberapa panas peranti semasa bermain game atau menonton video.

**Penggera suhu berlebih**

CPU Monitor membunyikan penggera saat suhu CPU atau bateri terlalu panas; penggera ini dapat diaktifkan atau dimatikan sesuai keinginan.

**Tetingkap terapung**

Tetingkap terapung memaparkan suhu CPU, suhu bateri, dan penggunaan RAM secara masa nyata, baik di bar status maupun di skrin utama.

**Widget**

Tersedia widget RAM, widget CPU, dan widget bateri.

**Beragam tema**

CPU Monitor mendukung pergantian multi-tema, sehingga Anda boleh memilih paparan yang disukai.
